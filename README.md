# React Todo App

A clean and intuitive task management application built with React.
The app allows users to create, edit, filter, complete, and manage tasks efficiently through a simple and user-friendly interface.
This project demonstrates component-based architecture, state management, and dynamic UI updates.

🔗 Here is [DEMO LINK](https://renata11111-afk.github.io/todoApp-project/)

## Technologies Used

- React
- TypeScript
- Vite
- HTML5
- SCSS

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Toggle all tasks (complete/uncomplete all at once)
- Filter tasks (All / Active / Completed)
- Responsive and clean UI
